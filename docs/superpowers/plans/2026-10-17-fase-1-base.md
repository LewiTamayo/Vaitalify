# Fase 1 — Base y pipeline · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar la API desplegable en Vercel con `/api/v1/health`, errores RFC 7807, validación de entorno, OpenAPI base, esquema Prisma completo con migración inicial, y el pipeline CI (lint + typecheck + tests + SonarQube Cloud).

**Architecture:** Express 5 en `src/app.ts` con `export default app` (entry zero-config de Vercel, sin `listen`); `src/local.ts` hace `listen` solo en local. Prisma 7 con driver adapter `@prisma/adapter-pg` (sirve igual para Neon con pooling y para el `postgres:16` del CI). Todo el código es stateless.

**Tech Stack:** Node 24 · TypeScript 6.0.x · Express 5.3 · Prisma 7.10 + `@prisma/adapter-pg` · Zod 4 · `@asteasolutions/zod-to-openapi` 9 · Luxon · pino · helmet · Vitest 5 + Supertest + `@vitest/coverage-v8` + `vitest-sonar-reporter` · ESLint 10 + `typescript-eslint` + `eslint-plugin-sonarjs` · Prettier.

**Spec:** `.claude/spec.md` (fuente de verdad) + `docs/superpowers/specs/2026-10-17-vitalify-api-design.md` (decisiones U-1…U-9 que lo ajustan). Leer ambos: §0, §2, §3, §4.2, §5, §9, §12, §17, §18.

## Global Constraints

- Código e identificadores en español como el modelo ER; JSON en `camelCase`; horas `"HH:mm"`, fechas `"YYYY-MM-DD"`, instantes ISO-8601 UTC.
- Prohibido: `console.log` (usar `pino`), `Math.random()`, estado en memoria entre peticiones, `setInterval`/`node-cron`, `app.listen` en `src/app.ts`, archivos `src/server.ts` o `src/index.ts`, `express.static`, `swagger-ui-express`.
- Complejidad cognitiva ≤ 15 por función; sin duplicación; sin secretos en el código (tests generan los suyos).
- "Hoy" siempre con `hoyEnZona()` en `APP_TZ=America/Bogota`, nunca `new Date()`.
- Versiones fijadas: `prisma`/`@prisma/client`/`@prisma/adapter-pg` **7.10.x** (el tag `latest` de npm es una RC de Prisma 8: no usarla); `typescript` **6.0.x** (`typescript-eslint` exige `<6.1`); `"engines": { "node": "24.x" }`.
- Base path de toda la API: `/api/v1` (incluye `/health`, `/docs`, `/openapi.json`).
- Errores siempre `application/problem+json` con `type = https://vitalify.app/errors/<slug>`, `title`, `status`, `detail?`, `errors?: {campo, mensaje}[]`, `hint?`. Mensajes en español. Sin stack en `production`/`preview`.
- Tests en `tests/` (nunca junto al código); unitarios en `tests/unit/**`, integración en `tests/integration/**`.
- Commits pequeños en la rama `fase-1-base`, mensajes convencionales en español, terminando con la línea `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. **Body JSON malformado o demasiado grande** → `400` (`slug=json-invalido`) o `413` (`slug=payload-demasiado-grande`) en problem+json, nunca HTML de Express ni `500`. Test en Task 3.
2. **Ruta inexistente** → `404` problem+json (`slug=no-encontrado`), no la página HTML por defecto. Test en Task 3.
3. **Base de datos caída o Neon suspendida/lenta** → `/health` responde `503 { status: "degraded", db: "down" }` en ≤ 3 s en vez de colgar la función hasta el timeout de Vercel. Tests en Task 5.
4. **`/docs` bajo `helmet`**: la CSP por defecto bloquearía Swagger UI desde CDN; la respuesta de `/docs` debe llevar una CSP que permita `cdn.jsdelivr.net`. Test en Task 5.
5. **Entorno inválido en producción** → la app no arranca y el error lista los **nombres** de las variables inválidas sin incluir sus **valores** (secretos). Test en Task 2.
